從語法糖到 runtime

Go 底層原理筆記

一份用台灣用語寫的 Go 語言設計與實作筆記 —— 編譯器怎麼翻譯你的程式碼、runtime 怎麼跑它、記憶體怎麼被管理。所有內容皆對照 Go 1.26 原始碼重新校對。

從頭開始讀 → 直接看目錄

對照最新版本

每一節都標注了對照的 Go 版本。凡是近年改過的地方（Swiss Table map、register ABI、Green Tea GC、1.22 迴圈變數、1.23 計時器）都會特別標出「舊版是這樣、現在是這樣」。

台灣用語

全書使用繁體中文與台灣慣用術語：執行緒、行程、記憶體、指標、佇列、排程器、快取。goroutine、channel、slice 這類無共識譯名的詞一律保留原文。

讀得懂的程式碼

範例都是可以直接 go run 的完整片段，並附上實際輸出。runtime 原始碼片段會標注檔案路徑，方便你自己翻原始碼對照。

Part 1

編譯器

從一份 .go 檔到一顆可執行檔，中間到底發生了什麼事。

  1. 1.1編譯流程總覽從 go build 到可執行檔，編譯器內部的六個階段各自負責什麼，以及怎麼把每個階段的中間產物 dump 出來看。
  2. 1.2詞法與語法分析token 是怎麼切出來的、分號為什麼會自動插入、語法樹長什麼樣子，以及 Go 語法設計背後對編譯速度的考量。
  3. 1.3型別檢查與泛型實例化types2 做了哪些事、Go 的型別身分規則、介面滿足如何判定，以及泛型的 GC shape 實例化策略。
  4. 1.4中間表示與 SSAwalk 階段如何把語法糖改寫成 runtime 呼叫、SSA 是什麼、以及編譯器在 SSA 上做了哪些最佳化。
  5. 1.5逃逸分析、內聯與 PGO編譯器如何決定變數放堆疊還是堆積、函式能不能被內聯，以及 profile 引導最佳化怎麼用。
  6. 1.6機器碼生成與連結Plan 9 組合語言、暫存器配置、連結器的死碼消除，以及執行檔裡到底塞了哪些東西。

Part 2

資料結構

array、slice、map、string 在記憶體裡真正的樣子。

  1. 2.1陣列 array為什麼陣列長度是型別的一部分、值語意帶來的複製成本，以及編譯器對陣列做的最佳化。
  2. 2.2切片 slice三欄位標頭、append 的擴容規則、共享底層陣列造成的別名陷阱，以及三索引切片與記憶體洩漏。
  3. 2.3雜湊表 mapGo 1.24 把 map 從 bucket 鏈結換成 Swiss Table。控制字元組、可延伸雜湊、為什麼走訪順序是隨機的、以及為什麼不能取 map 元素的位址。
  4. 2.4字串 string字串的兩欄位結構與不可變性、byte 與 rune 的差別、字串拼接的成本，以及零複製轉換的正確做法。

Part 3

語言核心

函式呼叫慣例、介面的動態分派、反射與泛型的實作方式。

  2. 3.2介面 interfaceiface 與 eface 的兩字組結構、itab 怎麼建立與快取、nil 介面的經典陷阱，以及型別斷言與 switch 的成本。
  3. 3.3反射 reflectreflect.Type 與 reflect.Value 怎麼從介面來、可設定性（settability）的三個條件、struct tag 的解析，以及反射的真實成本。
  4. 3.4錯誤處理與傳遞error 就是一個介面、誰該接住錯誤、%w 與 errors.Is/As 的包裝鏈，以及為什麼 goroutine 是錯誤傳遞鏈的斷點。

Part 4

關鍵字

那些看起來像語法、其實是編譯器改寫成函式呼叫的關鍵字。

  1. 4.1for 與 rangerange 被改寫成什麼、Go 1.22 迴圈變數的語意變更、range 陣列與 slice 的差異，以及 Go 1.23 的 range over func 迭代器。
  2. 4.2selectselectgo 的四步驟、隨機選擇為什麼是必要的、空 select 與 default 的特殊處理，以及常見的 select 慣用寫法。
  3. 4.3defer三種 defer 實作路徑（開放編碼、堆疊、堆積）、參數何時求值、迴圈中 defer 的陷阱，以及具名回傳值與 defer 的互動。
  4. 4.4panic 與 recovergopanic 怎麼展開堆疊、recover 為什麼只能在 defer 裡用、哪些錯誤 recover 攔不住，以及什麼時候該 panic。
  5. 4.5make 與 new兩個內建函式的分工、它們各自被改寫成哪個 runtime 呼叫、零值可用的設計原則，以及 Go 1.26 對 new 的擴充。

並行

  2. 5.2同步原語與鎖Mutex 的正常模式與飢餓模式、RWMutex 的寫入者優先、WaitGroup 與 Once 的實作，以及 atomic 與記憶體模型。
  3. 5.3計時器 timerGo 1.23 的計時器重寫、四叉堆積的組織方式、Timer 與 Ticker 的正確用法，以及舊版的洩漏陷阱。
  4. 5.4channelhchan 的結構、有無緩衝的差異、直接交遞最佳化、關閉的規則，以及 goroutine 洩漏的成因與防範。
  5. 5.5GMP 排程器G、M、P 三者的分工、工作竊取、hand-off、非同步搶佔，以及 GOMAXPROCS 該怎麼設。

  7. 5.7系統監控 sysmon那條不需要 P 就能執行的監控執行緒，它負責搶佔、回收系統呼叫中的 P、強制 GC 與歸還記憶體。
